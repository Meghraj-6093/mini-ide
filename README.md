# mini-ide

A browser-based mini IDE built with React, TypeScript, Tailwind CSS, and Monaco Editor.

## Features
- File management (create, edit, delete)
- JavaScript/TypeScript code editing with Monaco Editor
- In-browser code execution with console output
- Tabs, command palette, and keyboard shortcuts
- Dark-themed developer interface

## Getting Started

```bash
npm install
npm run dev
```
